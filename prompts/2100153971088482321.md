**提示词**

```text
INPUT: $ SUBJECT              // 神秘生物、未分类人形、门前不对劲的异物
VISITOR   = infer_subject($ SUBJECT)        // 与门框的比例、姿势、对镜头的察觉
BEHAVIOR  = infer_mundane_act($ SUBJECT)    // 正在做一件普通寻常的事——翻垃圾、拧门把手、拿包裹
PORCH     = infer_porch($ SUBJECT)          // 真实的墙板、地垫、花盆、水管、剥落的油漆
NIGHT     = infer_ir_night($ SUBJECT)       // 红外发射器开启、单色黑白、无色彩信息
BLOWOUT   = infer_ir_falloff($ SUBJECT)     // 靠近镜头的主体曝光过度泛白、背景死黑
LENS      = infer_fisheye($ SUBJECT)        // 严重的桶形畸变、边缘拉伸
MOUNT     = infer_camera_height($ SUBJECT)  // 约4英尺高、固定安装、轻微倾斜未调平
CROP      = infer_motion_trigger($ SUBJECT) // 主体部分出画——被截断、正在进入
OVERLAY   = infer_hud($ SUBJECT)            // 时间戳、设备名称、电池图标、小号字体
FLAWS     = infer_flaws($ SUBJECT)          // 低码率涂抹拖影、红外噪点、压缩色块
Φ = ir_falloff(emitter) + barrel_warp(LENS)
MOTION: 主体从画面边缘进入 → 停顿 → 头部转向镜头 → 保持不动2秒 → 离开。
无镜头移动，固定机位。
Compose: 固定门铃摄像头，红外夜视模式，黑白单色，主体曝光过度且部分出画，时间戳覆层，严重压缩伪影。逼真写实，4:3 或 16:9。
```
