```text
创作一张高端竖版编辑对比海报，以一条干净笔直的中线上下精确各占50%分割。上半部分：[SUBJECT]的逼真旅行摄影，拥有自然光线、真实质感、仅做轻微的杂志级调色——保持照片的真实感，切勿在上半部分进行插画化处理。下半部分：同一主体在暖白色肌理纸上的稀疏黑色蜡笔动态速写研究——带着迟疑感的断续蜡笔轮廓线、不完整的填充、纸张纹理、从照片中取样的一两处轻微彩色蜡笔涂抹痕迹。几乎删去所有背景；仅保留一条微弱的地面线或墙壁暗示。主体大部分为纸白留白空间，未完全填充。主体约占底部宽度的38–58%，位于中下方。连续的暖白留白空间≥55%。清晰易读的手写颤抖蜡笔法语文本：一个简短标题、« ÉTUDE CRAYON 0N »，以及一条法语的事实性观察记录。无英文文本。避免毛发细节、可爱的矢量吉祥物、全填色、密集的涂鸦、完整的背景、平滑的数码铅笔线条、产品插图、标志、签名、水印。主题选项：un chat roux sur les pavés (PAUSE RUE / ÉTUDE CRAYON 01)、valises empilées près de la porte (PRÊT À PARTIR / ÉTUDE CRAYON 02)、un vélo contre le mur (ATTENTE / ÉTUDE CRAYON 03)、une tasse encore chaude (PETITE PAUSE / ÉTUDE CRAYON 04)。
```
